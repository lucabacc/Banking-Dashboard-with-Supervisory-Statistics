# ECB Banking Dashboard 📊

## 📌 Project Overview

The project provides an example of a supervisory dashboard using SUP Data, in a comparison between Italy and Spain in an aggregate sample for SII Institutions.  

The dashboard provides a visualization of key risk metrics:
- CET1 Ratio  
- Liquidity Coverage Ratio  
- Non Performing Loans Ratio  

---

## 📡 Data Source

Data are directly downloaded from:

**European Central Bank (ECB) Supervisory Banking Statistics (SUP)**  
https://data.ecb.europa.eu/data/datasets/SUP
